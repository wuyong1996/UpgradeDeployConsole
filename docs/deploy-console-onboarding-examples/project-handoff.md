# 工程接入交接清单

填写后与无敏感值样例一起交付。实际密码、Token、私钥和带密码连接串不写在本文中。

| 项目 | 填写内容 |
| --- | --- |
| 项目名称 / 负责人 / 联系方式 | 待填写 |
| 建议项目标识 | 例如 `project`；最终以面板标识为准 |
| Git 地址 / 分支 | 待填写 |
| 私有仓库认证方式与安全交接渠道 | 待填写；不填凭据值 |
| 仓库根 `deploy-console.json` 已提交的 commit | 待填写 |
| Node / npm / .NET SDK / 运行时版本 | 待填写；附版本约束文件 |
| 前端源码相对目录 | 待填写；无前端则写不适用 |
| 前端安装、构建命令 / 工作目录 | 待填写 |
| 前端产物目录（相对构建目录） | 待填写 |
| 前端 API 前缀 / 路由模式 / 基路径 | 待填写；默认模板代理 `/api/` |
| 前端构建变量（只填非敏感值） | 待填写 |
| 后端 Web 项目路径 / 程序集名称 | 待填写；无后端则写不适用 |
| 后端健康接口及检查哪些依赖 | 待填写 |
| 后端配置键名、必填项、无密钥样例 | 待填写 |
| 上传等持久目录 / 写权限需求 | 待填写 |
| 数据库类型、版本 / 实例是否共享 | 待填写 |
| 数据库新建还是已有 / 当前迁移版本 | 待填写 |
| 初始化、升级脚本及离线迁移协议 | 待填写；自动模式需实现计划、应用与可选初始化命令 |
| 迁移执行账号、重复执行行为、验证 SQL | 待填写 |
| 与旧应用兼容性 / 失败恢复说明 | 待填写 |
| 数据库模式 | 自动创建项目库 / 现有库只检测 / 管理实例；自动模式仅暂停项目账号访问 |
| 其他运行依赖、外部连接及访问限制 | 待填写 |
| submodule / LFS / 私有依赖源等额外步骤 | 待填写；无则写无 |
| 域名 / HTTPS / 外部端口 | 待填写 |
| 自动更新周期 / 维护窗口 | 待填写 |
| 验收用例 / 验收人 | 待填写 |
