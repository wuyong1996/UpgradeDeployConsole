# 自动端口范围升级

> 下列历史版本的包已按用户要求不再保留。当前请按[最新打包与部署说明](deploy-console-package.md)获取完整包，并使用生成的DEPLOY.md安装；以下功能与排查说明继续适用。

前后端自动分配端口现限定为 **15000–25000，包含15000和25000**，从小到大寻找可用端口。

- 先排除已登记服务及其变更后的端口；已停止的服务仍保留端口。
- 再检测IPv4和IPv6地址能否绑定，跳过已使用或无法使用的端口。
- 同次前端和后端分配不同端口；范围全部占用时提示错误，不分配范围外端口。
- 已接入项目继续使用原端口。本次修改自动分配规则，手动端口操作及数据库端口不变。

## 在服务器安装

将 `deploy-console-server-20260924-ports.tar.gz` 用WinSCP上传至 `/root/`。等当前发布任务完成后，在root终端执行：

先将新版`upgrade-deploy-console.sh`上传至`/root/`，覆盖旧脚本；无需上传校验文件。

```bash
bash /root/upgrade-deploy-console.sh /root/deploy-console-server-20260924-ports.tar.gz
```

新版脚本不读取或要求`.sha256`。升级包存在则安装，不存在则提示跳过安装；两种情况均在面板健康检查通过后，清理能够确认与当前安装内容一致的同版解压目录，以及本次包和可选的旧校验文件。不存在的文件直接跳过。支持本次临时目录、旧版随机解压目录及直接解压的同名上传目录；解压外层含其他文件、存在软链接、挂载点、其他版本或内容不符的目录会保留并说明原因。安装/健康检查失败时保留现场。旧压缩包内说明不更新，请使用这里的新脚本；不会把“缺包跳过”报告为“已升级”。

新版包包含已交付的“总开始”功能，保留面板密码、MySQL连接和项目状态；只更新部署面板及其适配器。新接入或补接缺失的一端使用新端口规则，重复发布已有服务不会重新分配端口。

核对服务器已更新：

```bash
grep -E '^AUTO_PORT_(MIN|MAX) =' /usr/local/lib/deploy-console/provision.py
```

应输出：

```text
AUTO_PORT_MIN = 15000
AUTO_PORT_MAX = 25000
```

之前的SDK版本不匹配是独立问题，仍需让服务器具备项目要求的SDK才能构建后端。本次不会安装SDK、发布业务项目或执行数据库迁移。

检测通过到真正启动之间，面板以外的程序仍可能抢占端口；这种情况由现有启动和健康检查报告失败。真实Linux服务验收需在服务器完成，Windows本地测试不替代服务器验证。
